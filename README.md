# Qrixeva

Qrixeva is a QR code platform that helps users create, customize, manage and share QR codes.

## 🌐 Live Website

https://qrixeva.vercel.app/

## ✨ Features

* Create QR codes easily
* Customize QR code appearance
* Create different types of QR codes
* Create QR codes for links, text, contact details, Wi-Fi, UPI and more
* Create QR experiences for files and digital information
* Download and share QR codes
* Manage QR codes from your account
* View QR code activity and analytics
* Personal dashboard for each user

## 🔐 Account

Users can create their own account and manage their QR codes and information from their personal dashboard.

Each user's data should remain private to their own account.

## 🛠️ Built With

* Next.js
* React
* TypeScript
* Supabase
* PostgreSQL
* Vercel

## 🚀 Run Locally

Clone the repository and install dependencies:

```bash
git clone https://github.com/sathwikchilapuram/qrixeva.git
cd qrixeva
npm install
npm run dev
```

Create a `.env.local` file in the root directory and add your environment variables (see `.env.example` for required keys).

Then open `http://localhost:3000` in your web browser.
